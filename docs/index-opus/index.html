Git History, as Cognitive Memory

Spectral Cortex converts your repository's commit history into a Spectral Memory Graph — a structured, queryable memory layer that lets AI agents retrieve why code changed, not just what.

The Problem

Your codebase knows why it changed.
But nobody can find the answer.

Developers spend an average of 1.4 hours per incident performing "git archaeology" — tracing blame through refactors, sifting through noisy logs, piecing together intent from squashed diffs. AI agents hit the same wall: context windows can't hold a monorepo.

How It Works

From raw commits to queryable memory in three stages

Spectral Cortex is a single Rust binary. Ingest your repo, build the graph, and query it via CLI or serve it as an MCP server for AI agent integration.

1

Ingest & Filter

High-speed Rust parsers walk your git history. Configurable filters strip noise — Co-authored-by, merge lines, CI metadata. The ast split mode uses tree-sitter to bind commit hunks to language-level symbols (functions, classes, structs) in Rust, TypeScript, JavaScript, and Python.

2

Embed & Cluster

Each segment is embedded with a local MiniLM model (no API calls, no network). Identical content is batch-deduplicated. Spectral graph construction clusters related notes and computes scored adjacency links and long-range cross-cluster connections.

3

Retrieve & Serve

Query via CLI for JSON output, or launch the built-in MCP server. Hybrid retrieval combines vector similarity with keyword-based metadata boosting and temporal re-ranking to surface the most actionable context. Every result carries full provenance — commit IDs, timestamps, scores, and related notes.

spectral-cortex
# Ingest with AST-aware splitting
spectral-cortex ingest \
  --repo /my/project \
  --out smg.json \
  --git-commit-split-mode ast \
  --git-filter-preset git-noise

Core Capabilities

Engineered for
precision retrieval

account_tree

AST-Aware Splitting

Tree-sitter parses diffs and binds each hunk to the nearest enclosing function, class, or struct. Multi-change commits become multiple semantically focused notes.

bubble_chart

Spectral Graph Topology

Eigengap-driven clustering organizes notes into logical neighborhoods. Tunable num_spectral_dims, min_clusters, and max_clusters let you match your architecture.

link

Long-Range Links

Discovers connections between spectrally similar but embedding-distant notes — revealing architectural relationships that keyword search will never find.

schedule

Temporal Re-Ranking

Exponential-decay recency scoring biases results toward fresh context. Configure weight, half-life, and mode — or disable entirely for time-agnostic retrieval.

find_replace

Hybrid Search

Combines embedding-based semantic similarity with keyword boosting on symbol IDs, file paths, and metadata. Filter results by --file or --symbol for surgical queries.

verified

Full Provenance

Every retrieved note carries source commit IDs, timestamps, scores, cluster labels, and related-note links. Agents can cite evidence directly. Nothing is opaque.

Agent Integration

Six highly focused
MCP tools

Run spectral-cortex mcp --smg smg.json and your AI agent gains structured, markdown-first access to the entire graph. Designed for token efficiency — compact outputs that reduce prompt bloat.

graph_summary
Get compact metadata about the loaded graph — note count, clusters, link stats.
query_graph
Semantic query with markdown tables, scored results, and related-note summaries.
inspect_note
Deep-dive into a single note — its content, provenance, and spectral neighborhood.
long_range_links
Discover cross-cluster connections missed by embedding similarity alone.
get_structural_hotspots
Find the most frequently modified AST symbols — the brittle parts of your system.
inspect_symbol_history
Chronological evolution of a specific function or class across all commits.
Use Cases

Built for real
engineering workflows

🔍

Regression Investigation

Ask "why was this behavior introduced?" and get commit-grounded evidence with semantic connections to related changes — no manual blame digging required.

🏗️

Refactor Archaeology

Trace the history of a specific function across all refactors. Understand structural decisions made months or years ago, even when the original authors are gone.

🧭

Codebase Onboarding

New to a 50k-commit monorepo? Query for how a subsystem evolved instead of reading files one by one. The graph surfaces the important architecture decisions.

🤖

Agent Grounding

Wire the MCP server into Claude, Gemini, or any MCP-compatible agent. Every tool response includes verifiable commit evidence — no hallucinated history.

🔥

Hotspot Detection

The get_structural_hotspots tool surfaces the most frequently modified symbols. Find the brittle code that keeps breaking before it breaks again.

🔄

Continuous Memory

Wire spectral-cortex update into a post-commit hook. The graph stays fresh automatically — incremental ingestion only embeds new commits.
